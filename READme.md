Описание и загрузка датасета (https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html).
Инструменты: Python, pandas, matplotlib, scikit-learn. Работу выполнить в Jupyter Notebook или Google Colab.
Загрузка данных
